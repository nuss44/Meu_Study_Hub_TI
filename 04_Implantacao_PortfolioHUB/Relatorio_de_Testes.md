**Objetivo:** Verificar se o PortfolioHUB abre corretamente.

O site carregou normalmente pelo GitHub Pages, apresentando a estrutura HTML e a formatação CSS.

### T02 — Navegação entre Seções

**Objetivo:** Verificar o funcionamento do menu de navegação.

**Resultado:** Aprovado.

As opções Sobre Mim, Habilidades, Disciplinas, Projetos e Contato direcionaram corretamente para suas respectivas seções.

### T03 — Botão GitHub

**Objetivo:** Verificar o direcionamento ao repositório.

**Resultado:** Aprovado.

O botão GitHub abriu corretamente o repositório Meu_Study_Hub_TI.

### T04 — Botão LinkedIn

**Objetivo:** Verificar o direcionamento ao perfil profissional.

**Resultado:** Aprovado.

O botão LinkedIn direcionou corretamente ao perfil profissional.

### T05 — Responsividade

**Objetivo:** Verificar a adaptação do site para dispositivos móveis.

**Ferramenta:** Chrome DevTools.

**Resultado:** Aprovado.

A interface apresentou textos legíveis, cards organizados verticalmente e adaptação à largura da tela de celular.

Na captura analisada, não foram observados elementos ultrapassando a largura visível.
