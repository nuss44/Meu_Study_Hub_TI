
# Guia de Colaboração — PortfolioHUB

## 1. Apresentação

Este documento estabelece as orientações de
colaboração, compartilhamento e controle de
versões do PortfolioHUB.

Autor: Vitor Andrade de Moura

O projeto foi desenvolvido durante a disciplina
Bootcamp I, do curso de Ciência de Dados.

## 2. Organização do Repositório

O PortfolioHUB utiliza o GitHub para armazenar
os arquivos, controlar as alterações e
compartilhar os projetos.

As principais pastas são:

- 01_Apresentacao_e_Perfil
- 02_Disciplinas_Atuais
- 03_Projetos_e_Certificados
- 04_Implantacao_PortfolioHUB

## 3. Gestão de Colaboradores

Atualmente, o repositório não possui
colaboradores adicionais.

O proprietário é responsável por administrar
as permissões e revisar as modificações.

Novos colaboradores somente deverão ser
adicionados quando houver necessidade.

## 4. Controle de Versões

O projeto utiliza Git e GitHub para registrar
e acompanhar alterações.

A branch principal é denominada main.

A primeira versão do projeto foi
identificada pela tag v1.0.

Novas alterações serão registradas
por meio de commits descritivos.

## 5. Padrão de Commits

As mensagens dos commits devem explicar
as modificações realizadas.

Exemplos:

- docs: atualizar documentacao
- feat: adicionar nova funcionalidade
- fix: corrigir erro no site
- style: melhorar aparencia da interface
- security: atualizar configuracoes de seguranca

## 6. Procedimento de Colaboração

Caso sejam realizadas contribuições futuras,
recomenda-se o seguinte procedimento:

1. Criar uma branch para a alteração.
2. Desenvolver ou atualizar os arquivos.
3. Verificar o funcionamento das modificações.
4. Registrar as alterações em commits.
5. Enviar a branch ao GitHub.
6. Abrir um Pull Request.
7. Revisar as alterações antes da integração.

Atualmente, por ser um projeto individual,
o proprietário administra diretamente
as atualizações do repositório.

## 7. Compartilhamento

O repositório está configurado como público,
permitindo a visualização do código-fonte.

Repositório:
https://github.com/nuss44/Meu_Study_Hub_TI

Site:
https://nuss44.github.io/Meu_Study_Hub_TI/

O compartilhamento público não concede
automaticamente permissão para modificar
os arquivos do projeto.

## 8. Segurança nas Contribuições

Antes de enviar alterações, deve-se verificar
se os arquivos não contêm:

- Senhas.
- Tokens de autenticação.
- Chaves de API.
- Chaves privadas.
- Informações pessoais sensíveis.

As práticas de segurança estão descritas
no arquivo SECURITY.md.

## 9. Documentação

Novos projetos deverão possuir arquivos
README.md contendo:

- Descrição do projeto.
- Objetivos.
- Tecnologias utilizadas.
- Instruções de utilização, quando aplicáveis.
- Resultados e melhorias futuras.

## 10. Considerações Finais

Estas orientações foram criadas para
padronizar as contribuições e melhorar
a organização do PortfolioHUB.

O objetivo é manter um repositório
documentado, seguro e preparado para
evoluções futuras.
