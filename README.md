
# Meu Study Hub TI

Bem-vindo ao meu Study Hub!

Este repositório foi desenvolvido como parte da disciplina
Bootcamp I, com o objetivo de organizar minha trajetória
acadêmica, registrar projetos e construir um portfólio
profissional na área de Tecnologia da Informação.

## Sobre mim

Sou estudante de Ciência de Dados e também possuo formação
em Relações Internacionais.

Tenho interesse em Análise de Dados, Business Intelligence,
Inteligência Artificial e automação de processos.

Meu objetivo é aprimorar minhas habilidades técnicas,
desenvolver projetos práticos e compartilhar minha evolução
acadêmica e profissional.

## Projeto principal — Study Hub

O Study Hub é um site estático desenvolvido utilizando
HTML e CSS e publicado por meio do GitHub Pages.

O projeto apresenta informações sobre minha trajetória,
habilidades, disciplinas, projetos e contatos.

### Funcionalidades

- Navegação entre as seções do portfólio
- Apresentação de habilidades e interesses
- Organização das disciplinas acadêmicas
- Seção dedicada aos projetos
- Links para GitHub e LinkedIn
- Layout adaptável a diferentes tamanhos de tela
