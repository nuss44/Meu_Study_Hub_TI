
# Interação Humano-Computador (IHC)

## Apresentação

Esta pasta reúne as atividades, anotações, exercícios e projetos desenvolvidos durante a disciplina de Interação Humano-Computador, do curso de Ciência de Dados.

A disciplina estuda a interação entre pessoas e sistemas computacionais, buscando desenvolver interfaces intuitivas, acessíveis e eficientes.

## Objetivos da Disciplina

- Compreender os fundamentos da Interação Humano-Computador.
- Conhecer os princípios de usabilidade e acessibilidade.
- Estudar a experiência do usuário (UX).
- Compreender os fundamentos de interface do usuário (UI).
- Desenvolver interfaces utilizando HTML, CSS e JavaScript.
- Aplicar técnicas de prototipação.
- Avaliar a qualidade e a facilidade de uso de interfaces.

## Conteúdos da Disciplina

### Fundamentos de IHC

- Conceitos de Interação Humano-Computador.
- Ergonomia e fatores humanos.
- Princípios de usabilidade.
- Acessibilidade digital.

### Experiência e Interface do Usuário

- User Experience (UX).
- User Interface (UI).
- Design centrado no usuário.
- Organização e navegação de interfaces.
- Avaliação de interfaces.

### Desenvolvimento Web

- HTML para estruturação de páginas.
- CSS para estilização visual.
- JavaScript para interatividade.
- Criação de interfaces responsivas.

### Prototipação

- Planejamento de interfaces.
- Criação de protótipos.
- Testes de usabilidade.
- Identificação de melhorias.

## Organização da Pasta

### Atividades_e_Entregas

Destinada aos exercícios, projetos de interfaces, protótipos e trabalhos acadêmicos desenvolvidos durante a disciplina.

### Anotacoes_e_Resumos

Destinada aos resumos, conceitos, materiais de estudo e anotações utilizados para revisar os conteúdos.

## Projeto Prático Previsto

Desenvolver ou prototipar uma interface digital aplicando princípios de usabilidade, acessibilidade e experiência do usuário.

O projeto poderá envolver planejamento, criação de protótipos e desenvolvimento de páginas utilizando HTML, CSS e JavaScript.

## Competências Desenvolvidas

- Planejamento de interfaces digitais.
- Aplicação de princípios de UX/UI.
- Desenvolvimento básico de páginas web.
- Avaliação de usabilidade.
- Identificação de problemas de acessibilidade.
- Criação de protótipos funcionais.

## Considerações Finais

A disciplina de Interação Humano-Computador contribui para minha formação em Ciência de Dados ao desenvolver conhecimentos sobre a relação entre usuários e sistemas digitais.

Esses conhecimentos também poderão ser aplicados na construção de dashboards, sistemas de análise de dados e outras soluções tecnológicas com foco na experiência do usuário.
