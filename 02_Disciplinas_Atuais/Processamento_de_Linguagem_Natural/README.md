
# Processamento de Linguagem Natural (PLN)

## Apresentação

Esta pasta reúne as atividades, anotações, exercícios e projetos desenvolvidos durante a disciplina de Processamento de Linguagem Natural, do curso de Ciência de Dados.

A disciplina aborda técnicas computacionais utilizadas para analisar, interpretar e processar a linguagem humana, permitindo o desenvolvimento de aplicações de Inteligência Artificial baseadas em textos.

## Objetivos da Disciplina

- Compreender os fundamentos do Processamento de Linguagem Natural.
- Conhecer técnicas de pré-processamento de textos.
- Aplicar métodos de análise e representação textual.
- Estudar técnicas de aprendizado de máquina aplicadas à linguagem.
- Compreender processos de classificação e análise de sentimentos.
- Conhecer aplicações práticas de PLN.
- Desenvolver habilidades para trabalhar com dados textuais.

## Conteúdos da Disciplina

### Fundamentos de PLN

- Introdução ao Processamento de Linguagem Natural.
- Aplicações de PLN na Inteligência Artificial.
- Representação e processamento de textos.

### Pré-processamento de Textos

- Tokenização.
- Remoção de stopwords.
- Stemming.
- Lematização.
- Limpeza e normalização de textos.

### Análise Linguística

- Part-of-Speech Tagging (POS Tagging).
- Análise sintática (Parsing).
- Extração de informações.
- Identificação de estruturas linguísticas.

### Aprendizado de Máquina e PLN

- Classificação de textos.
- Modelagem de tópicos.
- Análise de sentimentos.
- Aplicações de Machine Learning em dados textuais.

## Organização da Pasta

### Atividades_e_Entregas

Destinada aos exercícios, códigos, trabalhos acadêmicos e projetos desenvolvidos durante a disciplina.

### Anotacoes_e_Resumos

Destinada aos materiais de estudo, resumos, explicações e anotações relacionados aos conteúdos apresentados nas aulas.

## Projeto Prático Previsto

Desenvolver uma aplicação de Processamento de Linguagem Natural para analisar um conjunto de textos.

Como possibilidade de projeto, poderá ser desenvolvida uma análise de sentimentos de avaliações ou comentários, utilizando técnicas de pré-processamento e classificação de textos.

## Competências a Desenvolver

- Preparação e tratamento de dados textuais.
- Aplicação de técnicas de processamento de linguagem.
- Análise e interpretação de textos.
- Utilização de métodos de Machine Learning.
- Desenvolvimento de aplicações básicas de PLN.
- Identificação de padrões em informações textuais.

## Considerações Finais

A disciplina de Processamento de Linguagem Natural contribui para minha formação em Ciência de Dados ao apresentar técnicas utilizadas no desenvolvimento de soluções de Inteligência Artificial.

Os conhecimentos adquiridos poderão ser aplicados futuramente em projetos de análise de sentimentos, classificação de textos, automação e outras aplicações baseadas em linguagem natural.
