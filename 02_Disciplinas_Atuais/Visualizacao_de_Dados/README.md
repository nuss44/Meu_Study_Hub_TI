
# Visualização de Dados

## Apresentação

Esta pasta reúne os materiais, exercícios e projetos da disciplina Visualização de Dados, do curso de Ciência de Dados.

A disciplina tem como objetivo desenvolver habilidades para transformar dados em gráficos, dashboards e outras representações visuais que facilitem a compreensão das informações.

## Objetivos

- Compreender os princípios da visualização de dados.
- Conhecer diferentes tipos de gráficos.
- Criar dashboards e visualizações interativas.
- Aplicar princípios de design visual.
- Interpretar dados e identificar tendências.
- Comunicar resultados de maneira clara.

## Conteúdos da Disciplina

- Gráficos de barras, linhas e dispersão.
- Mapas e diagramas.
- Dashboards interativos.
- Design visual: cores, tipografia e layout.
- Visualizações estáticas e dinâmicas.
- Análise e interpretação de informações.

## Organização da Pasta

### Atividades_e_Entregas
Destinada aos exercícios, trabalhos, gráficos e projetos desenvolvidos na disciplina.

### Anotacoes_e_Resumos
Destinada aos materiais de estudo, resumos das aulas e revisões dos conteúdos.

## Projeto Prático Previsto

Desenvolver um conjunto de visualizações para analisar dados e apresentar resultados relevantes por meio de gráficos, dashboards ou relatórios.

## Considerações Finais

Esta disciplina contribui para minha formação em Ciência de Dados, permitindo desenvolver habilidades de análise, interpretação e comunicação visual de informações.
