
# Bootcamp I — Study Hub

## Apresentação

Esta pasta reúne as atividades, anotações e projetos desenvolvidos durante a disciplina Bootcamp I, do curso de Ciência de Dados.

O objetivo é organizar meu aprendizado, acompanhar minha evolução e construir um portfólio acadêmico e profissional.

## Objetivos da Disciplina

- Aprender os fundamentos do Git e GitHub.
- Organizar projetos em repositórios.
- Utilizar controle de versionamento.
- Desenvolver uma página web com HTML e CSS.
- Publicar projetos utilizando GitHub Pages.
- Documentar projetos com arquivos README.md.
- Integrar o portfólio ao LinkedIn.

## Estrutura da Pasta

- Atividades_e_Entregas: trabalhos e atividades acadêmicas.
- Anotacoes_e_Resumos: materiais de estudo e revisões.

## Projeto Study Hub

O Study Hub é um portfólio acadêmico desenvolvido com HTML5 e CSS3, utilizando Git e GitHub para controle de versões.

O site apresenta informações sobre minha trajetória acadêmica, habilidades, disciplinas e projetos.

### Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

### Versionamento

Versão inicial: v1.0

O projeto continuará sendo atualizado conforme o desenvolvimento de novas atividades e melhorias.
