
# Projetos Acadêmicos

## Apresentação

Esta pasta reúne os projetos acadêmicos desenvolvidos durante minha graduação em Ciência de Dados.

O objetivo é documentar atividades práticas, registrar conhecimentos adquiridos e demonstrar a aplicação dos conteúdos estudados.

## Objetivos

- Organizar projetos das disciplinas.
- Aplicar conhecimentos teóricos na prática.
- Desenvolver habilidades técnicas.
- Documentar metodologias e resultados.
- Construir um portfólio acadêmico.

## Áreas de Desenvolvimento

### Ciência de Dados
Projetos envolvendo coleta, tratamento, análise e interpretação de dados.

### Business Intelligence
Desenvolvimento de dashboards, indicadores e relatórios utilizando ferramentas de análise de dados.

### Inteligência Artificial
Estudos e aplicações envolvendo Machine Learning e Processamento de Linguagem Natural.

### Desenvolvimento Web
Projetos envolvendo HTML, CSS, JavaScript e construção de interfaces.
